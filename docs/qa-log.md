## 2026-10-22 1.0.3 (versionCode 18)
- 포함: 첫 설치 시 사용 방법 자동 표시(1.0.2 이하에서 업데이트한 사용자 제외), 문서 화면 "페이지를 누르면 회전·순서 변경" 안내(그리드 첫 줄), 9개 언어 번역 점검.
- Play 경고 "디버그 기호 미업로드" 확인: 번들의 네이티브 코드는 androidx.graphics.path(Compose 내부)의 미리 빌드된 .so 하나뿐. `debugSymbolLevel = SYMBOL_TABLE` + 러너 NDK(30.0)로 빌드해도 extractReleaseNativeSymbolTables 출력이 비어 있음(이미 기호가 제거된 라이브러리라 뽑을 기호가 없음). 앱 코드에는 네이티브 코드가 없으므로 경고는 해소 불가·불필요로 판단, 설정은 되돌림. 출시·심사 영향 없음.
- 별도 QA 검토로 잡은 것: 업데이트 사용자에게도 도움말이 뜨는 문제 → 기존 설정값 있으면 생략. 안내 문구가 고정 줄로 화면을 차지 → 그리드 항목으로. 도움말이 각 언어 버튼 이름과 다름(Min., ドキュメント, दस्तावेज़) → 통일. "Nothing is uploaded"가 광고 SDK 통신과 혼동 소지 → "문서는 업로드되지 않음"으로 범위 명확화.
- 테스트: SmallScreenTest에 페이지 있는 문서 화면(독일어·320dp) 안내·하단 버튼 표시 확인 추가.
