# 출시 계획

## 신규 개인 개발자 계정 조건
프로덕션 신청 전 비공개 테스트: 테스터 12명 이상이 14일 연속 참여(옵트인 유지).

## 테스터 확보안 (비용 0원)
1. 지인 Gmail 계정 수집 (가족·친구) — 가장 확실
2. 무료 상호 테스트 커뮤니티: Reddit r/AndroidClosedTesting, r/TestersCommunity 등에서 서로 테스트 교환
3. 유료 테스터 대행(1~2만원대)은 정책 위반 소지·품질 문제로 비추천

## 순서
1. CI로 서명된 AAB 생성
2. Play Console: 앱 생성 → 스토어 등록정보(영문 기본+현지화) → 개인정보처리방침 URL → Data safety → 콘텐츠 등급 → 광고 포함 표시
3. 비공개 테스트 트랙 업로드 + 테스터 이메일 등록 → 14일 시작 (가능한 빨리)
4. 테스트 기간 중 피드백 반영 업데이트
5. 14일 후 프로덕션 신청 (검토 수일)
6. AdMob: 앱 등록 → 광고 단위(배너·전면) → 실ID를 GitHub Secrets에 → app-ads.txt(선택)
