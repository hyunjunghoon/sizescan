# 1호 앱 설계 (가칭 SizeScan)

## 한 줄
무료 문서 스캐너. 계정·워터마크·장수 제한 없음. PDF/JPG를 원하는 용량(예: 50KB, 200KB 이하)에 맞춰 저장·공유.

## MVP 기능
1. 스캔: Google ML Kit Document Scanner (테두리 인식·보정·필터·여러 장, 카메라 권한 불필요)
2. 사진 가져오기: 시스템 Photo Picker (권한 불필요), EXIF 회전·투명 배경 보정
3. 문서 관리: 목록, 이름 변경, 삭제, 페이지 추가·삭제 (앱 내부 저장소, 서버 전송 없음)
4. 내보내기: PDF/JPG × 용량 제한(원본, 50/100/200/300/500KB, 1/2MB, 직접 입력)
   - 1KB = 1000바이트 기준으로 맞춰 1024 기준 포털도 통과
   - 화질 55 이상 유지하며 해상도부터 줄이고, 한계에서만 화질 하향
   - PDF는 JPEG를 재인코딩 없이 직접 삽입하는 자체 작성기 → 용량 예측 정확
5. 저장(SAF, 권한 불필요) / 공유(FileProvider)

## 광고 (AdMob만, 유료 결제 없음)
- UMP 동의(유럽 등) 후 광고 요청, 개인정보 설정 메뉴 제공
- 홈 하단 적응형 배너 1개
- 파일 생성 완료 시 전면광고: 첫 내보내기 제외, 최소 2분 간격
- 스캔·편집 도중에는 광고 없음
- 3번째 내보내기 후 Play 인앱 리뷰 요청 1회
- 워터마크를 광고로 제거하는 방식은 쓰지 않음 (차별점이 "워터마크 없음", 반발 우려)
- 보상형 광고(v1.1 예정): 기본 기능은 전부 무료로 두고, 가끔 쓰는 고급 기능(예: 20장 이상 일괄 처리)만 "광고 보고 이번만 열기"로 제공. 강제 아님

## 기술
Kotlin 2.2 / Compose(BOM 2025.06) / AGP 8.11 / minSdk 26 / targetSdk 36(2026-08 이후 신규 앱 필수)
패키지: io.github.hyunjunghoon.docscan (영구, 앱 이름과 무관)
다국어: en(기본), ko, es, pt-BR, hi, id, de, fr, ja
빌드: GitHub Actions(테스트·lint·APK·AAB). 사용자 PC 사용 안 함.
