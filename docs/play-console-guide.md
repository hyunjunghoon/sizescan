# Play Console 등록 순서 (사용자 계정 필요 단계만)

PC 브라우저 권장(휴대폰은 "데스크톱 사이트"로). 회사 PC 말고 개인 기기에서.

## 1. 앱 만들기
play.google.com/console → **앱 만들기**
- 앱 이름: `SizeScan: PDF Scanner & KB Fit`
- 기본 언어: English (United States) – en-US
- 앱 / 무료 → 선언 2개 체크 → **앱 만들기**

## 2. 비공개 테스트 트랙 + 업로드
왼쪽 **테스트 및 출시 > 테스트 > 비공개 테스트** → **트랙 만들기**(이름: closed)
- **테스터** 탭 → 이메일 목록 만들기 → 테스터 Gmail 12개 이상 입력 → 저장
- **새 버전 만들기** → Play 앱 서명 "계속" → AAB 업로드: `app1-builds/sizescan-1.0.0.aab`
- 버전 이름 그대로, 출시 노트: `First test build.` → **다음** → **저장 후 검토 시작**

## 3. 대시보드 "앱 설정" 항목 (복사해서 입력)
- 개인정보처리방침: `https://hyunjunghoon.github.io/sizescan/privacy.html`
- 앱 액세스 권한: 모든 기능 제한 없이 사용 가능
- 광고: **예, 광고 포함**
- 콘텐츠 등급: 설문 → 카테고리 "유틸리티, 생산성…" → 폭력·성적 내용 등 전부 "아니요"
- 타겟층: **13세 이상** 전체 선택(13–15, 16–17, 18+)
- 데이터 보안(Data safety):
  - 데이터 수집/공유: 예
  - 기기 또는 기타 ID: 수집·공유 / 목적: 광고 또는 마케팅, 분석 / 선택 아님
  - 앱 상호작용, 비정상 종료 로그·진단: 수집 / 목적: 분석
  - 전송 중 암호화: 예 / 삭제 요청: 아니요(서버 데이터 없음)
- 정부 앱: 아니요 / 금융 기능: 없음 / 건강: 없음
- 앱 카테고리: **생산성** / 이메일: 본인 이메일
